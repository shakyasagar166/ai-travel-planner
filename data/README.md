# Travel Data Catalog

This directory contains database schemas and seed datasets for the AI Travel Planner Agent.

## Files:
* `schema.sql`: Complete MySQL DDL definitions for users, destinations, attractions, accommodations, trips, user preferences, and conversation history.
* `destinations.json`: Curated dataset with 8 diverse destinations (Goa, Manali, Jaipur, Kerala, Tokyo, Paris, Bali, Dubai) including rich attractions, stays, and budget profiles.
